# 矿山管理系统开发需求文档（全栈项目）

请基于以下详细需求，为我生成一个完整的矿山管理系统。技术栈要求：后端使用 **Python（推荐 FastAPI 或 Django）** 或 **Java（Spring Boot）**；前端不限（推荐 React + Ant Design / Element Plus）。数据库推荐 PostgreSQL 或 MySQL。

## 1. 系统角色与权限架构
- **总管理员账户**（超级管理员）：
    - 唯一最高权限账户。
    - 拥有所有矿山管理账户的**创建**与**禁用**权限。
    - 拥有系统所有数据的**修改最高权限**（包括修改各矿山的财务、设备核心数据）。
    - 可查看全局汇总看板。
- **矿山管理账户**（分矿账号）：
    - 由总管理员创建，绑定特定矿山（例如：矿山A管理员、矿山B管理员）。
    - 登录后仅能查看和管理自己所辖矿山的 设备、人员、财务、发车 数据。
    - 拥有对应模块的增删改查权限。

## 2. 全局技术细节要求
- **多货币支持**：涉及金额字段需支持 **美元（USD）** 和 **刚果法郎（CDF）**，输入时需强制选择币种，展示时需分开统计。
- **数据导入导出**：所有批量操作需支持 **Excel (.xlsx)** 格式，后端需提供解析模板下载和上传解析接口（推荐使用 Apache POI for Java 或 OpenPyXL / Pandas for Python）。
- **数据隔离**：矿山管理账户的所有查询操作，后端必须自动过滤 `mine_id` 字段，防止跨矿数据泄露。

## 3. 功能模块详细需求

### 模块一：设备管理模块（核心：工时与油耗计算）

**主页面（Dashboard）**：
- 显示**本月**设备总工时（小时）和总油耗（升/加仑）。
- 数据可视化图表：折线图或柱状图展示每日油耗趋势（横轴日期，纵轴油耗量）。

**子功能页面设计**：
1. **设备管理页面**：
   - 功能：增、删、改、查设备基础信息。
   - 数据字段：`设备编号`（唯一）、`设备名称`、`设备品牌`、`设备类型`（挖掘机/卡车/装载机等）。
   - **批量导入**：提供 Excel 模板下载，支持按上述4列格式批量导入设备列表。

2. **数据录入页面**：
   - 用于录入每日/每次作业后的原始数据。
   - 表单包含：选择设备、`工作日期`、`工作时长（小时）`、`加油量（升）`、`备注`。

3. **数据修改页面**：
   - 列表形式展示已录入的工时与油耗记录。
   - 支持按日期范围搜索。
   - 点击记录可修改 `工作时长` 和 `加油量` 数值。

4. **报表下载页面**：
   - **设备工作时间明细表（按月）**：导出 Excel。列头：`日期` | `设备编号` | `设备名称` | `设备工作时间` | `设备工时` | `备注`。
   - **设备本月汇总表（按月）**：导出 Excel。列头：`设备编号` | `设备名称` | `设备总工时` | `设备总油耗` | `设备日均油耗`。
   - **计算公式**：`日均油耗 = 总油耗 / 当月工作天数`（注意除零处理）。

### 模块二：人员管理模块

**主页面**：
- 展示人员列表，支持按工种、姓名搜索。

**子功能页面设计**：
1. **刚方人员导入**：
   - **批量导入模板**：Excel 表头固定为：`姓名（法语）` | `中文音译` | `工种` | `月工资（USD或CDF）` | `币种`。
   - 导入时需校验工资币种枚举值。

2. **人员修改**：
   - 支持编辑人员信息、调整工资。
   - 支持**软删除**或物理删除人员记录。

3. **人员工资表导出**：
   - 一键导出当前矿山所有在职人员工资单 Excel，包含字段：姓名、工种、工资金额、币种。

### 模块三：财务管理模块（双币种记账）

**主页面**：
- **收入与支出总览卡片**：分别显示 美元收入/支出 和 刚果法郎收入/支出（按当月统计）。
- **费用分析图**：饼图展示支出分类占比（如：燃油费、工资、维修费、其他）。

**子功能页面设计**：
1. **记账系统（流水账）**：
   - 列表展示所有收支记录，支持按币种筛选。
   - **录入表单**：`交易类型`（收入/支出）、`金额`、`币种`（USD/CDF）、`录入人`（自动填充当前登录账户）、`用途说明`、`交易日期`。
   - **重要约束**：前端展示时，**严禁直接将美元金额与刚郎金额相加**，必须分币种展示合计。

### 模块四：发车管理模块（车牌比对逻辑）

**主页面**：
- **工厂发车统计卡片**：显示不同工厂（如：采矿场、选矿厂）的本月总发车次数。
- **车牌跑趟排行榜**：表格展示 `车牌号` 及 `本月跑车次数`。

**子功能页面设计**：
1. **授权车牌录入**：
   - 功能：管理员预先录入拥有进出权限的车牌号码库。
   - 支持单条添加、批量导入。

2. **装车车牌录入**：
   - 功能：每次装车时，现场人员记录实际装载的车牌号及时间。
   - 记录字段：`车牌号`、`装车时间`、`发货工厂`、`货物类型`。

3. **发货工厂管理**：
   - 简单的增删改查维护工厂名称（如：1号采矿点、2号堆浸场）。

4. **车牌比对分析（核心算法）**：
   - 功能触发：在装车记录列表页点击“比对分析”按钮，或定时任务自动分析。
   - **比对逻辑**：找出所有 **实际装车车牌** 但**未在授权车牌库**中登记的记录。
   - **结果展示**：生成 **差异车牌清单**，显示 `车牌号`、`装车时间`、`所属工厂`，标注“未授权”。

## 4. 数据库设计提示

请设计合理的数据库表结构，关键表建议包含：
- `mine_account` (矿山账户表，关联 mine_id)
- `equipment` (设备表)
- `equipment_work_log` (工时油耗记录表)
- `employee` (人员表，含工资字段及币种)
- `finance_record` (财务流水表，含金额、币种、类型)
- `authorized_plate` (授权车牌表)
- `shipping_record` (装车记录表)
- `factory` (工厂表)

3. 前端实现关键页面的布局和交互逻辑（至少包含仪表盘和主要表单）。
